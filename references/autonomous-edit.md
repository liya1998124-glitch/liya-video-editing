# 一键剪辑包装流程

一句话触发后，Agent 主动跑完下面的流程。字幕初稿和样片是工作过程中的文件，最终应导出经过检查的成片。

1. **找素材与内容**。仅盘点用户指定或已授权的素材范围。对视频、图像、音频和工程做清单，抽帧看人物、动作、画幅和成品内容。按口播事件建立素材映射，每个引用记录文件与片内起止。先用当条原片与用户自己的旧素材，再用合适的原创图形。真实演示缺失时用已明确标注的示意，或向用户索取必须的素材。只有主片归属不清、关键词拼法会影响发布、授权或付费动作缺确认等阻断交付的问题才询问。询问期间继续能做的工作。
2. **主动做动画**。有多个作品时先考虑播放中的胶片。只有一条口播时，可按真实词时绘制素材缩略片飞入、片段依次进轨、播放头扫描、原画与包装的擦除对照、波形跳动或其他贴合内容的原创动效。至少做一个有内部运动、能说明本片内容的动画。按语义复杂度增加独立镜头。用当前可用的动画工具，或在本地用代码生成逐帧图形。检查生成片段是否可播放，画面是否真的发生变化。图解带「示意」标签，展示旧素材带「往期作品」标签。
3. **剪辑合成**。把实录、胶片和生成的动画写入时间轴的 motion 列表或当前编辑器分轨，原声作时间基准。在词时加入标题、词条、字幕与提示音。口播未授权重剪时保留原始剪口。图形音效位置遵守用户指定，混音后人声清楚。片尾关键词使用用户确认的字面拼写，所有画面与字幕一致。
4. **验收并交付**。先检查各个独立镜头，再检查最终导出。胶片中的各格要播放，词条、播放窗和时间线错开，保持人脸与手势可见。确认开头、中段、片尾的实际帧，整片音画解码。工具缺失时切可执行的本地方法，报告尚缺的依赖或能力。成片、SRT、可重跑时间轴及新生成素材保存在用户指定目录。记录实际素材和哪些动画已合进去。
