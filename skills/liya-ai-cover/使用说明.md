# 一键封面与三平台发布文案使用说明

## 先安装

从网盘下载 `liya-ai-cover.zip`，按你使用的工具选择一种方法。

- **Codex**。把 ZIP 发给 Codex，或告诉它文件位置，再说「请帮我解压并安装这个 Skill，保留整个文件夹，装好告诉我怎么调用」。项目目录可用 `.agents/skills/liya-ai-cover/`。安装后新开对话。
- **WorkBuddy**。在「技能 → 添加技能 → 上传技能」选择 ZIP，导入后在「已安装」确认启用。 [WorkBuddy 官方说明](https://www.codebuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Skills-Market)
- **Claude**。网页和桌面聊天版在「自定义 → Skills」上传 ZIP。用 Claude Code 时，可请它把完整文件夹解压到项目的 `.claude/skills/liya-ai-cover/`。 [Claude 官方上传说明](https://support.claude.com/en/articles/12512180-use-skills-in-claude)

## 开始使用

1. 发本期脚本、字幕或清楚的内容摘要。要真人出镜就附本人清晰的正脸照，可再附一张有表情或动作的照片。要放数据、截图、品牌图标，请提供本期有权使用的原件。
2. 有标题就直接给标题。没有标题时让 Agent 根据本期脚本拟写，指定是否可删虚词。可指定自然实景、手持科技道具、科技拼贴、纸感手账等，也可以交给 Agent 判断。
3. 说明封面要 3:4、9:16 或两张。改稿时可说「标题放到下半张」「人物保留，主标题放大」「12 万是往期截图，请标清」。看一眼手机缩略图再定稿。
4. 收图和发布文案。抖音 5 个话题，小红书 10 个并自然加入长尾搜索词，视频号 5 个。有额外平台限制可在任务里说明。
