# 一键封面与三平台发布文案使用说明

1. 解压后保留完整的 `liya-ai-cover` 文件夹，请 Agent 安装到当前工具的 Skills 目录，或在对话中提供文件夹位置并让它读取 `SKILL.md`。
2. 发本期脚本、字幕或清楚的内容摘要。要真人出镜就附本人清晰的正脸照，可再附一张有表情或动作的照片。要放数据、截图、品牌图标，请提供本期有权使用的原件。
3. 有标题就直接给标题。没有标题时让 Agent 根据本期脚本拟写，指定是否可删虚词。可指定自然实景、手持科技道具、科技拼贴、纸感手账等，也可以交给 Agent 判断。
4. 说明封面要 3:4、9:16 或两张。改稿时可说「标题放到下半张」「人物保留，主标题放大」「12 万是往期截图，请标清」。看一眼手机缩略图再定稿。
5. 收图和发布文案。抖音 5 个话题，小红书 10 个并自然加入长尾搜索词，视频号 5 个。有额外平台限制可在任务里说明。
