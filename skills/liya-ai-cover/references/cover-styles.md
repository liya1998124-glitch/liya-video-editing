# 封面构图与风格

先按内容选风格，再决定标题落点。参考图只拆构图、透视、色彩、光线、层次和字重。人物身份、服装、案例和统计来自本次授权素材。

| 风格 | 适合 | 构图与执行 |
| --- | --- | --- |
| 手持道具的广角近景 | 工具介绍、实操演示 | 用前景手持工具图标建立透视，指尖自然扣住道具。道具和手可以有夸张近大远小，脸保留自然比例。背景用真实工作空间或明亮玻璃编辑室，胶片、声波只起辅助作用。 |
| 下半幅冲击大字 | 短标题、数字型选题 | 人脸和主道具居上，主标题优先铺满下半区，可拆两到三行并加描边。允许删虚词或可舍弃的修饰词时先缩文案。标题位置挤压时先减装饰，再检查脸、手和证据卡是否遮挡。 |
| 温暖实景教程 | 工具入门、教程、经验 | 奶油白、自然木色或中性实景，真人腰部以上或自然坐姿。标题靠上，单个产品图标或演示卡靠近指向的手。适合保留真实服装与日常表情。 |
| 双手展示流程 | 多个工具、步骤拆解 | 真人居中，左右两手分别托住主题图标或操作卡。可用胶片、时间线、浮动卡片补充步骤，卡片有大小、近远和层级差异。工具多时以主用工具为最大焦点。 |
| 立体科技拼贴 | 剪辑、自动化、软件工作流 | 大标题、人物、工具卡组成主次，影片片孔、剪辑轨、波形作为可识别的动作线索。前后层错位、局部透视与光线呼应，避免等大卡片排一圈。 |
| 纸感手账 | 账本、复盘、生活教程 | 用奶油纸、牛皮纸、纸边和文字条纹表现手账。人物保持真实。票据样式作为原创示意，明细只使用可对外展示且有来源的数据。 |
| 新闻或案例拼贴 | 有证据的趋势解读、往期作品 | 真人或主题道具是主角，真实截图进入小窗并注明归属，例如往期作品、直播画面。保留原数字，事实信息清楚可读，避免看起来像本条的新数据。 |
| 无真人的产品封面 | 无授权肖像、教程、账号系列 | 用工具或物件作中心，放大主词和实际使用收益。可用授权截屏或原创示意作第二层，用深浅、遮挡与比例形成纵深。 |

## 制作与检查

- 精确指定文案原字、比例、人物身份参考、风格参考的分工。不想改文字时独立排版，局部调整标题可直接重排。
- 三种包装主色以内，白色也计入。原照片和原始截图自然色保留。紫色可用浅粉紫、深紫形成同色层次，重点数字可用白或亮黄提升反差。
- 手持透视可以生成新姿势，按生成画面检查手指、腕部连接和脸。站姿、坐姿、两手托物及飞行感分别使用，选择由内容与授权决定。
- 3:4 常用 1080×1440，9:16 常用 1080×1920。双比例分别排版。3:4 注重缩略图密度，9:16 把脸、标题和证据放进中间的可视区，再逐张看手机缩略图。
- 成片画面、历史数据、不同产品的商标或示意图要标对归属。公开 Skill 包只保留这份文字方法。
